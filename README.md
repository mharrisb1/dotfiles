# dotfiles

Originally, this started as a simple project of directories that would be manually symlinked to [`$XDG_CONFIG_HOME`](https://specifications.freedesktop.org/basedir-spec/latest/#variables). Now, this project serves as my portable setup for multiple hosts. My job often involves me needing to setup new physical or virtual machines for development on Ubuntu 22+. Over the years I have crafted a developer experience that meets my needs and I needed a way to quickly setup that experience on every new machine.

## Setup

Setup a fresh Ubuntu install:

```bash
wget -qo- https://raw.githubusercontent.com/mharrisb1/dotfiles/main/install.sh | bash
```
